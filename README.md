## Publicar no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório.
2. Em Settings > Pages, selecione `main` e `/(root)`.
3. Abra o endereço HTTPS no celular.
4. Toque em **Instalar E-3906 concept** ou use a opção de instalação do navegador.
